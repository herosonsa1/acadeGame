# 페어웨이 소풍 (Fairway Picnic) v1.1

골프 라운딩 현장에서 1번 홀 티샷 순서를 정하거나 그늘집 커피 내기, 캐디피 및 식사 복불복, 스킨스 팀 편성을 즐길 수 있는 안드로이드 아케이드 캐주얼 게임 앱입니다. 따뜻한 수채화 감성의 지브리풍 배경과 캐릭터 아바타, 로비 및 게임별 어쿠스틱 배경음악, 결정적 순간의 슬로우모션과 심장박동 효과음을 하나로 묶었습니다.

## v1.1 주요 기능

- 결과 순위 배지 6색 완전 분리: 1위부터 6위까지 모든 결과 행의 순위 배지와 아바타 테두리에 서로 다른 고유 색상(`#B85233`, `#2E6F4E`, `#356B96`, `#9A6B24`, `#6B5087`, `#2F7678`)을 부여해 동반자 순위가 한눈에 구분됩니다.
- 전 게임 공통 선수입장 및 2클릭 이름 조합기:
  - 기본 명단(`1번캐디백~4번캐디백`), 2차 프리셋(`1번참가자~4번참가자`), 직접 설정한 명단 프리셋을 원터치로 전환할 수 있습니다.
  - 다빈도 성씨 11종(`김씨, 박씨, 이씨, 정씨, 최씨, 강씨, 조씨, 윤씨, 장씨, 임씨, 한씨`)과 골프 호칭 6종(`프로, 사장, 회장, 선배, 선수, 대표`)을 두 번 눌러 `김씨 -> 김프로`처럼 즉시 조합하거나 직접 입력할 수 있으며 다른 게임으로 이동해도 명단이 그대로 유지됩니다.
- 게임 진행 시간(`5초 · 10초 · 15초`) 설정: 현장 분위기에 맞춰 게임 시작부터 최종 결과 도출까지의 연출 시간을 5초, 10초(기본값), 15초 중에서 선택할 수 있습니다.
- 지브리풍 사운드트랙 및 휴대폰 볼륨 실시간 연동:
  - 로비 및 카테고리별 어쿠스틱 루프 배경음악 4종과 7종 게임 전용 시작·진행·클라이맥스·결과 효과음을 내장했습니다.
  - 휴대폰 소리 모드가 무음이면 자동으로 음소거되고 휴대폰 측면 볼륨 버튼 및 외부 스피커·블루투스 미디어 볼륨이 마스터 볼륨으로 즉시 반영됩니다. 사운드 설정 창에서 배경음악, 진행 효과음, 심장박동, 결과 팡파르 채널을 개별적으로 켜고 끄거나 볼륨을 미세 조절할 수 있습니다.

## 수록 미니게임 (총 7종)

### 1홀 티샷 순서 정하기 (3종)
| 게임명 | 핵심 규칙 및 연출 |
| --- | --- |
| 드라이버 티 바운스 | 원형으로 둘러선 동반자 중앙의 드라이버 헤드에 나무 티를 튕겨 잔디에 떨어뜨립니다. 티의 끝이 가리킨 사람이 1번 오너가 되며 오른쪽 순서로 2, 3, 4번 타순이 정해집니다. |
| 나무 홈 뽑기 막대 | 가죽 통에 꽂힌 나무 막대를 뽑아 아래쪽에 파인 홈 개수(1~4개)로 타순을 결정합니다. 막대가 통 밖으로 올라오는 순간 슬로우모션이 발동합니다. |
| 숲속 오솔길 사다리 | 동반자 골프공이 통나무 다리 갈림길을 따라 홀컵으로 내려갑니다. 타순 결정 모드와 커피 1명 당첨 모드를 모두 지원합니다. |

| 게임명 | 핵심 규칙 및 연출 |

| 언덕 위 풍차 룰렛 | 클럽하우스 나무 풍차 바퀴를 돌려 커피·간식·캐디피 끝전 당첨자를 뽑습니다. 정지 직전 바늘이 황동 못을 넘나드는 슬로우모션이 적용됩니다. |
| 행운의 나무 패 뒤집기 | 섞인 나무 패를 골라 동시에 뒤집어 커피 당첨자를 뽑거나 청솔 A팀과 단풍 B팀으로 편을 나눕니다. |

## 기술 구성 및 빌드 방법

- 언어 및 프레임워크: Kotlin 2.3, Jetpack Compose Material 3, Android SDK 36 (minSdk 26)
- 사운드 및 진동: `AudioTrack` 16-bit PCM 실시간 파형 사전 합성 엔진 (`GhibliSoundEngine`), `AudioManager.STREAM_MUSIC` 마스터 연동 및 `VibrationEffect` 동기화
- 빌드 명령어: `./gradlew testDebugUnitTest assembleDebug assembleRelease`
